ThinkLens — private local AI prototype

START
Double-click Start-ThinkLens.cmd and leave its window open.
Open http://127.0.0.1:8765/ThinkLens.html
The launcher uses this computer's bundled Python, or Python 3 via the py launcher.
Alternative: run python server.py from this folder.
No Python packages need installing.

CONNECT YOUR CHATGPT ACCOUNT
Live AI uses the official Codex CLI with ChatGPT sign-in, not a separate API key.
Codex CLI must be on PATH. It is already installed on this computer.
Run codex login in a terminal and finish signing in using ChatGPT in the browser.
In ThinkLens click Check connection, choose Live AI, then Explore the language.
If already signed in, simply use the app. Check status with codex login status.
Do not paste passwords or tokens into the app or chat.

USE
Choose an example, paste English text, or import a public article URL.
Link import automatically analyzes with the currently selected engine.
Click highlights for an explanation, a possible effect, a neutral question,
and an alternative interpretation. Filter using the category buttons.
The live engine returns a short rhetorical overview and up to 18 suggested cues.
The account's default Codex model is selected by the CLI; the app does not
force a model or change your global Codex configuration.
The offline demo uses a small fixed phrase list and does not contact AI.
The overall-impression card shows a face, color, and a four-level cue indicator.
Levels reflect matched-sentence coverage: zero, below 35%, 35–69%, or at least 70%.
These are presentation thresholds, not validated measurements of influence.
The card also shows the AI overview in live mode and the leading detected categories.
Category filters affect highlights only; the overall result always covers the full input.

ACCOUNT AND LIMITS
Live analysis uses your signed-in Codex account and its applicable usage limits.
It is not an unlimited ChatGPT API. This app is local and private on your computer,
not a public website or shared AI service. Do not expose its server to the internet.
The initial live request can take longer; requests time out after three minutes.
One AI request runs at a time. If you edit text during a request the UI discards its
result; the server may still finish the in-flight analysis and consume account usage.
When analysis fails, the app shows an error instead of substituting demo findings.

DATA AND SAFETY
Live mode sends the supplied text to OpenAI using Codex under your account's
applicable data policies. It requests ephemeral sessions and captures the result
in memory. ThinkLens does not intentionally save submitted text, results, or URLs.
It does not extract account tokens or put credentials in the browser.
The CLI runs with a read-only sandbox, user configuration ignored for this request,
and shell, browser, plugins, apps, hooks, and delegation disabled for the analysis.
It operates in an empty .runtime folder; only its schema is stored in this project.
Managed account and machine policies still apply.
AI quotations are aligned against the exact input and validated before rendering.
Unmatched or ambiguous quotes are omitted with a count; if every proposed quote
fails alignment, the app returns an error. Overlapping classifications are preserved.
Statistics are computed from matched spans using browser English sentence segmentation,
not generated by the model. A flagged percentage is not a truth or manipulation score.
Neither AI nor phrase matching can establish a writer's actual intentions or honesty.
No external fact-checking is performed. AI interpretations can be wrong.

ARTICLE IMPORT LIMITS
Requires internet. Only public HTTP/HTTPS HTML or plain-text URLs are supported.
No paywall bypass or JavaScript rendering; some sites block automated requests.
Extraction normalizes whitespace and may omit content or include unrelated material.
Articles are limited to 12,000 UTF-16 character units, matching the browser textarea.
Truncation is labeled. Private and local network destinations are blocked.

FILES
ThinkLens.html — interface, offline rules, safe highlights, calculated statistics
server.py — local HTTP server and public article extraction
ai_engine.py — Codex sign-in check, prompt, invocation, validation, exact alignment
analysis-schema.json — structured output contract
tests/test_ai.py — alignment, validation, timeout, and adapter tests
Start-ThinkLens.cmd — local launcher
START-HERE.txt — presentation instructions

TEST
From this folder run: python -m unittest discover -s tests -v
Unit tests simulate model output; they do not consume account usage.
Verified in this build: a real signed-in Codex request and the complete browser
flow returned live model findings with validated highlights and explanations.
Article imports, demo examples, filters, input validation, and mobile layout were
also checked. Live model wording and classifications can vary between requests.
